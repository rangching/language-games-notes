# 語言遊戲：意義就是使用｜學習網頁

維根斯坦《哲學研究》與 AI 對照的 13 集教學系列的學習網頁：每集附原文短引、學習單、術語、練習、筆記、測驗與一個可以動手玩的互動模擬。上一季：[邏輯哲學論](https://rangching.github.io/tractatus-notes/)。

- 純靜態網頁（GitHub Pages），沒有建置步驟。內容在 `content.js`（由 `_units/` 合併產生），影片連結在 `videos.js`。
- `sims/`：各集的互動模擬，全部由頁內程式即時計算。
- `data/`：原文短引（德文為原文短句引用並標示節號；中文與英文為本系列自譯）、家族相似示範資料、生平地點與地圖底圖（Natural Earth 1:50m，公有領域；國界為現今國界）。
- `_units/calc_uNN.py`：練習題答案的計算程式。其中少數幾支會讀取作者端的來源資料檔，那些檔案不在這個 repo 裡。

第 10–13 集把語言遊戲與現代 AI 並排對照，是類比與啟發，不是歷史因果。

本機預覽：`python3 -m http.server 8203`
